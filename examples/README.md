## `data/`

| File | Description |
|---|---|
| `tableS1_ha30.fasta` | 30 influenza A HA genes from NCBI (accessions in the paper's Table S1) |
| `tableS1_ha30_meta.csv` | `name,subtype` metadata |
| `demo_ha30.fasta` | 30 simulated 1,700 bp sequences with a known tree |
| `demo_ha30_meta.csv` | simulated group labels |
| `demo_ha30_true.nwk` | true Newick tree for the simulated data |

## `results/`

| File | Description |
|---|---|
| `tableS1_scan.csv` | p-scan output (99 p values plus two FCGR baselines) used by `fig4_scan_p.png` |
| `tableS1_scan_ref.nwk` | Needleman–Wunsch + NJ reference tree for the scan |

## `figures/`

Generated by `scripts/make_figures.py`:

- `fig1_cgr_fcgr.png` — CGR walk and FCGR at two resolutions;
- `fig2_tree.png` — NJ tree of the 30 HA genes, colored by subtype;
- `fig3_mds.png` — classical MDS of the distance matrix;
- `fig4_scan_p.png` — RF and mean rank versus `p`.
